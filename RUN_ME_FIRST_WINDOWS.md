1) Download ZIP from GitHub (**Code → Download ZIP**) and extract it, or run `git clone <repo-url>`.
2) Open **PowerShell** inside the extracted/cloned project folder.
3) Run: `powershell -ExecutionPolicy Bypass -File .\scripts\setup-windows.ps1`
4) Paste your Supabase values when prompted.
5) Open the Admin Demo URL shown in PowerShell (`http://localhost:3000/admin/demo?token=...`).
